# 北京现代自动任务 APP (安卓端)

北京现代自动任务 APP 的安卓端源码。

## 功能

- 手机号短信登录后，点击添加账号，自动获取 token 保存到账号列表
- 支持多个账号，支持账号排序，删除
- 后台运行：任务在 **前台服务**中执行，退到后台甚至锁屏后仍能继续跑；完成后通知栏推送结果，点开可查看完整日志
- 答题准确率提升：固定使用 **百度千帆 AI 搜索**，把搜索到的资料连同题目一起交给 AI 分析
- AI 接口内置推荐参数： **智谱 GLM（免费）**，用户只需填 API Key；同时兼容任意 OpenAI 兼容接口
- 支持手动答题：前台弹窗选择；退到后台时通知栏点选答案， **点击通知正文会直接弹出选择框**（兼容
  MIUI/澎湃等会折叠通知按钮的国产 ROM），2 分钟未选则自动改用 AI/随机
- 支持青龙面板账号同步
